Berikut adalah analisis dan potensi penyebab dari kelima kendala tersebut: 1. Galeri Tidak Muncul Kemungkinan Penyebab: Path/URL Gambar Salah: Folder atau nama file gambar di dalam kode HTML/CSS tidak sesuai dengan struktur direktori aslinya (misalnya salah penulisan huruf besar/kecil atau ekstensi file seperti .jpg vs .png). CSS display: none atau visibility: hidden: Ada class styling yang tidak sengaja menyembunyikan kontainer galeri. Gagal Load JavaScript: Jika galeri menggunakan grid dinamis, filter, atau lightbox dari pustaka pihak ketiga (seperti Lightbox, Swiper, atau AOS), script tersebut mungkin gagal terpanggil atau ada error di konsol (browser console). 2. & 5. Backsound / Musik dan Background Tidak Muncul (Masalah nomor 2 dan 5 hampir serupa, berkaitan dengan aset media dan tata letak) Kemungkinan Penyebab Backsound (Musik): Autoplay Policy Browser: Hampir semua browser modern melarang pemutaran audio otomatis (autoplay) tanpa adanya interaksi pengguna (seperti klik tombol) terlebih dahulu. Jika audio dipaksa jalan saat halaman dibuka, browser biasanya akan memblokirnya. Sumber Audio (src): Link file musik (baik lokal maupun dari URL eksternal) rusak, terhapus, atau format filenya tidak didukung oleh browser. Kemungkinan Penyebab Background: Path Gambar/Warna Rusak: Sama seperti galeri, property seperti background-image: url(...) mengarah ke direktori yang keliru. Konflik CSS: Ukuran kontainer background tidak diatur (width atau height 0, atau background-size tidak sesuai), sehingga gambar tertutup elemen lain atau tidak kelihatan. 3. Maps Tidak Bisa Dibuka Malah Muncul Notif Firebase Kemungkinan Penyebab: Koneksi / Konfigurasi Firebase: Pesan "not firebase" atau error terkait Firebase biasanya muncul karena aplikasi mencoba mengambil data live (seperti daftar tamu, ucapan, atau titik koordinat peta dinamis) dari database Firebase, tetapi kunci API (API Key), konfigurasi firebaseConfig, atau aturan keamanan (Security Rules) belum diatur dengan benar atau sudah kedaluwarsa. Iframe Google Maps Rusak: Jika menggunakan embed Google Maps biasa namun ada skrip di sekitarnya yang terpengaruh error JavaScript/Firebase, elemen peta ikut gagal merender. 4. Fitur "Bantu Kami Abadikan Moment" Tidak Berfungsi Kemungkinan Penyebab: Formulir Terhubung ke Backend/Database yang Belum Siap: Fitur ini biasanya berupa form unggah foto atau link Google Drive/Form. Jika mengandalkan database (seperti Firebase Firestore atau Storage) untuk menyimpan data kiriman tamu dan konfigurasinya belum lengkap, tombol atau fungsinya akan "macet" saat diklik. Event Listener Belum Terpasang: Tombol interaktifnya mungkin belum memiliki fungsi JavaScript (addEventListener atau fungsi submit) yang aktif untuk merespons aksi klik dari pengguna.
